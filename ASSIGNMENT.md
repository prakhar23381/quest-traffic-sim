The QUEST Lab at the Department of Computational and Data Sciences, Indian Institute of Science, Bangalore, invites applications for the Full Stack AI Pre-doctoral Position, a full-time, on-site role for a minimum of 6 months and a maximum of 12 months. Competitive salary will be offered.

You will take ownership of deploying the lab's research results as working, maintained applications.

You will work with AI coding assistants every day. We are looking for drive, initiative, the judgement to tell right from wrong (including when the AI is wrong), the ability to stay on one task for a long time, discipline, and strong oral communication.

APPLICATION DEADLINE: 15 November 2026. Because of the volume we expect, no extensions or exceptions are possible.

SELF CHECK FIRST: last time we received 2,500 applications and hardly 25 cleared screening. If you are not sure, please do not overwhelm the application system. It takes a full week to apply when using frontier AI (and more than 2 months without). If you don't have the patience and discipline, please don't submit the form.

HOW TO APPLY: pick one of the three projects in this form and build it end to end, from data to a deployed application.
Rules:
1. All development must happen in one single Claude Code or Codex session. Nothing built outside it.
2. 72 hours at most, from your first prompt to your final commit.
3. Your first prompt must begin with the line: QUEST Lab Full Stack AI Pre-doctoral application, [your name], [date]
4. Commit to git from inside the session, so git history and the session log line up.
5. Submit the raw, unedited session log file (.jsonl). Claude Code stores these under ~/.claude/projects/ and Codex under ~/.codex/sessions/.

We read the log, not just the app. How you think, check and decide is what gets you selected.

Other models, other ways of working, and requests for part-time or remote work are welcome to apply, but are most likely not to succeed.

Pick one of the following 3
Project 1: Precipitation forecast app. Fetch precipitation forecasts from ECMWF Open Data (IFS or AIFS), process them, and deploy a web application that presents the forecast through an innovative front end and user experience.
Project 2: Traffic simulation. Build and run an agent-based model of traffic on a road network with junctions, flyovers and roads of different widths and capacities. Deploy it as an application where users set up scenarios and see results.
Project 3: PDE solutions as a service. Load a standard PDE dataset (for example from PDEBench: Burgers, Darcy flow, Navier-Stokes), train or adapt a model such as a neural operator, and deploy a full-stack application where users provide inputs and receive solutions.
