# Junction Lab

Agent-based traffic simulation of junctions and flyovers, including the Silk Board junction in
Bengaluru built from OpenStreetMap. Watch it live, close the flyover or change lanes and signal
timings, run the full period and compare scenarios.

Source, model description and validation report: https://github.com/prakhar23381/quest-traffic-sim

The free Space sleeps when idle; the first visit after a pause takes about 30 seconds to wake.
Saved short links are lost when the Space restarts, but links with the scenario in the URL
(`#s=...`) always work.

Map data © OpenStreetMap contributors, ODbL.
